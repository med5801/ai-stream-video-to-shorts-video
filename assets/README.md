# assets

Put the images you want the brain to use here (`.png`, `.jpg`, `.webp`).

- **The file name is the description.** The brain only sees file names, so name them well:
  `shocked_cat.png`, `pro_player_jersey.png`, `police_lights.png`.
- Transparent PNGs look best.
- You can add images **while a run is waiting for your review**: press `a` to open this
  folder, drop the image in, then type your idea (e.g. *"put pro_player_jersey.png when he says
  he's a pro"*). The folder is re-read on every brain call.
- Only use images you have the rights to use. This folder is git-ignored.
